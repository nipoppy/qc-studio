# Autoplay

Autoplay automatically advances to the next QC page on a timer.

## Turning it on and off

The controls are at the top of the sidebar on the QC page.

| Control | Effect |
|---------|--------|
| **▶️ Play** | Starts (or resumes) playback and begins the countdown for the current page |
| **⏸️ Pause** | Stops playback and clears the countdown |

Autoplay is **off** at the start of every session.

## Setting the duration

Set the countdown length on the landing page, under **👤 Rater Information**.

## Duration countdown

While playback is running, a countdown banner sits above the panels:

```text
⏱️  Next page in   3   s
```

## When autoplay pauses or stops

| Situation | What happens | Do you need to do anything |
|-----------|--------------|------------------|
| You start editing notes | Autoplay stops and the countdown is cleared | Click **▶️ Play** again to resume |
| You click **Next** manually | The page advances immediately and the countdown restarts from the full duration | Nothing |
| You click **Previous** manually | Same — the countdown restarts | Nothing |
| You use the sidebar filter | Autoplay continues, but only visits the **filtered** pages | Nothing |
| The timer expires on the last *filtered* page | Autoplay stops; the summary page is **not** opened while a filter is active | Clear the filter, then click **▶️ Play** |
| The timer expires on the last page with no filter active | Autoplay stops; the summary page opens only if every page is rated | Nothing |
